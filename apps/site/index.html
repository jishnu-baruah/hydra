/Hydra

Every build of your dApp, on public record.

Connect a wallet, get an API key, add one workflow file. Each push records the build on Arkiv and stores it on Swarm.

1 Connect your wallet

The wallet only signs a message. No transaction, no gas.

2 Name your app and get a key

Shown once. Store it as a repo secret named HYDRA_API_KEY.

3 Add Hydra to your repo

One copy: paste this into your coding agent (Claude Code, Cursor, Codex) opened in your repo. It sets the secret, writes the workflow and pushes. It contains your key, so paste it only into your own agent.
