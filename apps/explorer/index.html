How it works

  1. 01

    Publish

    CI sends each build. One API key, no gas.

    $ node hydra-publish.mjs dist
  hashed 24 files
  release 2026-11-06.1 recorded
  2. 02

    Record

    File hashes go to Arkiv. The build goes to Swarm.

    /index.html        9f2c1e..a41b
/assets/app.js     3b7d90..0c2e
/assets/vendor.js  e41a07..77f3
  3. 03

    Check

    The extension re-hashes the scripts a page loads and compares them with the release.

    OKEvery script matches the release
  4. 04

    Catch

    One changed file turns the badge red.

    !/assets/app.js is in no release
